# Chinnam Family — Gruhapravesam Invitation Website

A responsive English + Telugu static invitation website for 20 October 2026.

## Files
- `index.html` — the website
- `god-background.png` — user-provided deity image used as the first-page background
- `our-new-home.jpg` — user-provided house entrance photo shown in the gallery
- `README.md` — publishing notes

## Before sharing
1. Confirm the exact puja time and edit the countdown date/time in `index.html`; it currently uses 8:00 AM IST as a placeholder.
2. Confirm the exact Google Maps pin and address.
3. Add family/puja photos to the remaining gallery spaces if desired.
4. The welcome tune is a simple synthesized melody, not a song recording.
5. The RSVP opens WhatsApp with a pre-filled message; it does not save responses to a database.

## Publish free with GitHub Pages
1. Create a public repository, e.g. `chinnam-gruhapravesam`.
2. Upload **all three website assets** to the repository root: `index.html`, `god-background.png`, and `our-new-home.jpg`. (You may also upload this README.)
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Once deployment completes, the URL will look like `https://YOUR-GITHUB-USERNAME.github.io/chinnam-gruhapravesam/`.

Keep the image filenames exactly as shown so they load correctly. The site will be public to anyone with the link.
