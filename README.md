# Chinnam Family Gruhapravesam Invitation

Responsive static invitation website for GitHub Pages.

## Files
- `index.html` — complete mobile-first invitation with countdown, music control, venue links, and WhatsApp reply helper.
- `ganesha.png` — original generated Ganesha illustration used in the opening card.
- `home-landscape.jpg` — entrance photo for the wider-screen layout.
- `home-portrait.png` — portrait entrance image for mobile screens.

## Publish to the existing GitHub Pages repository
1. Open the repository `omkarchinnam/chinnam-gruhapravesam` on GitHub.
2. Upload these files to the repository root, replacing the old `index.html` and existing assets as appropriate.
3. Commit the changes to the branch configured for GitHub Pages. Wait for Pages to rebuild, then reload the live site.

## Before sharing
- Confirm the exact puja time before sharing; countdown points to the start of 20 October 2026 and does not assume a ceremony time.
- Verify the Google Maps venue pin. The link currently opens a Google Maps search for the provided address.
- The gallery includes the supplied illustrative Gruhapravesam artwork and home entrance images.
- Music is a short synthesized melody, not a recorded devotional song.
- WhatsApp replies open a prefilled message; no RSVP data is stored by this static site.


## Added invitation artwork
The package includes four traditional Gruhapravesam story images and decorative calendar, clock, and location illustrations supplied for this design. Confirm ceremony timing and exact venue pin before public sharing.
